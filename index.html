install

安装说明

安装包未做商业代码签名，系统会给出安全提示。下面三步只针对当前应用放行，不关闭系统保护。

01 / Windows x64
  1. 1

    运行安装程序

    双击 LeoDeepAI_0.5.2_x64-setup.exe，按向导完成安装。

  2. 2

    通过 SmartScreen

    若出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。

  3. 3

    启动并设置服务器

    登录页右上角「服务器」可填写并测试云服务地址。

02 / macOS arm64 / x64
  1. 1

    选对架构

    Apple Silicon（M 系列）选 aarch64.dmg，Intel 选 x64.dmg。可在「关于本机」里确认。

  2. 2

    拖进应用程序

    打开 dmg，把 LeoDeepAI 拖到「应用程序」文件夹。

  3. 3

    首次打开

    在 Finder 里右键 App →「打开」→ 再点「打开」。若仍被拦截，在终端执行 xattr -dr com.apple.quarantine /Applications/LeoDeepAI.app。

03 / Android debug
  1. 1

    下载通用 debug 包

    这个包同时包含 arm64-v8a、armeabi-v7a 和 x86_64，不需要再选架构。

  2. 2

    允许安装未知应用

    设置 → 应用 → 特殊权限 → 安装未知应用，给浏览器或文件管理器放行。

  3. 3

    安装并连接

    打开 APK 完成安装。登录页可设置云服务地址，默认是 https://api.leodeepai.com，联调时可改成自己的服务端。

NOTE 不登录也能用：桌面端支持自带 API Key 与本地 Ollama；平台模型、签到额度与手机配对需要登录账号。

2026-10-31 stable

Windows 0.5.2

  • 输入区改为富文本编辑：/技能名 与 @文件 在正文里渲染成引用 chip，输入法组词期间不重建 DOM，复制出来的仍是原始引用词。
  • 项目管理改为「一个项目 = 名字 + 一组并列文件夹」：文件夹可以来自多台服务器或本机；项目选择面板与左侧栏共用同一份项目悬停卡。
  • 设置新增「管理能力」页（插件 / 技能 / MCP），本机访问改为「用户明确要求才放行」，避免 AI 越出项目范围。
  • Agent 工具与项目文件夹作用域、传输队列、浏览器工具后端，以及文件管理器、终端面板细节同步更新。

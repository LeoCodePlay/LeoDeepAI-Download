02 — INSTALL

安装说明

安装包未做商业代码签名，系统会给出安全提示。下面三步只针对当前应用放行，不关闭系统保护。

(02 / 05)
01 / Windowsx64
  1. 1

    运行安装程序

    双击 LeoDeepAI_0.6.0_x64-setup.exe，按向导完成安装。

  2. 2

    通过 SmartScreen

    若出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。

  3. 3

    启动并设置服务器

    登录页右上角「服务器」可填写并测试云服务地址。

02 / macOSarm64 / x64
  1. 1

    选对架构

    Apple Silicon（M 系列）选 aarch64.dmg，Intel 选 x64.dmg。可在「关于本机」里确认。

  2. 2

    拖进应用程序

    打开 dmg，把 LeoDeepAI 拖到「应用程序」文件夹。

  3. 3

    首次打开

    在 Finder 里右键 App →「打开」→ 再点「打开」。若仍被拦截，在终端执行 xattr -dr com.apple.quarantine /Applications/LeoDeepAI.app。

03 / LinuxAppImage / deb
  1. 1

    选 AppImage 还是 deb

    AppImage 是单文件，任何发行版都能跑；deb 适合 Ubuntu / Debian，安装时会自动拉取 libwebkit2gtk-4.1 等依赖。

  2. 2

    安装或直接运行

    deb：sudo apt install ./LeoDeepAI_0.6.0_amd64.deb；AppImage：chmod +x LeoDeepAI_0.6.0_amd64.AppImage && ./LeoDeepAI_0.6.0_amd64.AppImage。

  3. 3

    首次启动

    如果提示缺少运行库，先装 libwebkit2gtk-4.1-0 与 libgtk-3-0；Wayland 下界面异常可用 GDK_BACKEND=x11 启动。

04 / Androiduniversal
  1. 1

    下载 universal 包

    这个包同时包含 arm64-v8a、armeabi-v7a 和 x86_64，不需要再选架构。

  2. 2

    允许安装未知应用

    设置 → 应用 → 特殊权限 → 安装未知应用，给浏览器或文件管理器放行。

  3. 3

    安装并连接

    0.1.4 是正式签名包，从旧 debug 包升级需先卸载。登录页可设置云服务地址，默认是 https://api.fournft.meme。

NOTE不登录也能用：桌面端支持自带 API Key 与本地 Ollama；平台模型、签到额度与手机配对需要登录账号。

桌面端 0.6.0（Windows / macOS / Linux）

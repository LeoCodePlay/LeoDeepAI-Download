# LeoDeepAI Android 1.0.2

发布日期：2026-11-17

- **聊天图片先出缩略图**：72px 格子只拉缩略图，点开大图才取原图；实测 30 张图的会话流量从约 51MB 降到约 0.24MB。
- **本地磁盘缓存**：200MB LRU 缓存，二次打开不再重新下载，断线重连不重复传输；退出登录会清空。
- **限并发与超时重试**：图片请求并发 3，缩略图 25s / 原图 55s 超时并自动重试一次；重连时旧请求作废。
- **引用与选区**：选中文字可「引用到对话」，@ 可引用其它会话与项目文件夹。

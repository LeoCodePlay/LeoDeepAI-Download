# LeoDeepAI 0.6.4

发布日期：2026-11-17

- **消息选区引用**：在对话里选中文字即可引用进输入框，引用卡片悬浮可预览原文。
- **文件路径可点击**：对话中的文件路径直接打开，带 `:行号` 的路径会定位到对应行。
- **主区与右侧栏互通**：图片、文件、浏览器预览等内容标签可以在主区与右栏之间互相拖动。
- **项目记忆**：按项目沉淀长期记忆，可在右栏查看、固定与删除。
- **图片查看器**：对话内图片支持放大查看与多图切换。
- **桌面端增强**：新增「保持系统唤醒」与开机自启开关；电脑操控（截图、坐标点击、窗口操作）更稳定。
- **交互细节**：侧栏项目分组支持编辑与拖拽、终端列表改版、全局悬停色阶统一。

# LeoDeepAI 0.6.7

发布日期：2026-11-24

- **设置页卡顿修复**：开机自启检测原来是非 async 命令、还要起 `reg.exe` 子进程读登录项，整段跑在 Tauri 的 UI 主线程上；进程创建加杀软扫描让设置面板一打开就卡住整个应用。现在改成 async 命令并直接读 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，设置页即开即用。
- **项目记忆 v2**：只提炼长期有效的「约束 / 工程约定 / 踩坑教训 / 重要决策」；本轮改动与待办改存会话归档，默认不再注入；旧版流水账可在面板里一键归档。
- **全局记忆**：跨项目的稳定偏好、长期方向、技术栈与环境约束，注入所有会话（含未绑定项目的对话），默认 12 条 / 1000 字，可在设置里开关与调整上限。
- **账号面板尺寸**：按登录态在 880×560（登录页）与 1040×780（账号中心）之间自动切换，与网页版弹窗保持一致。
- **图片附件**：缩略图按视口懒加载，图片查看器缓存与切换优化。
- **三平台同步构建**：Windows（NSIS x64）、macOS（Apple Silicon + Intel dmg）、Linux（AppImage + deb）。对应提交 `d41052a`，安装包内 BUILD.json 为干净工作区。

安装包：`LeoDeepAI_0.6.7_x64-setup.exe`（Windows x64 / NSIS）

SHA-256 见下载页校验表。

# LeoDeepAI Android 1.0.3

发布日期：2026-11-21

- **图片按视口加载**：对话里的附件图片滚到可见区域才请求缩略图，长会话不再一进页面就并发拉满；离开视口的请求会自动取消。
- **本地缓存**：缩略图、原图与高清分片统一落盘（200MB LRU），切回会话或重连后不再重复下载，退出登录会清空。
- **大图预览更顺**：点开先铺缩略图，再按电脑端切好的 WebP 分片逐段盖成高清，单帧只有几百 KB；保存到相册时按 1.2MB 分块下载并拼回原图，超过 32MB 会提示到电脑上查看。
- **上下文水位**：会话内可单独调小上下文上限，每个对话独立；新建对话自动回到模型最大值。
- **输入框**：引用与附件插到上一次光标处，不再总是追加到末尾；修复行尾凭空多出空行。

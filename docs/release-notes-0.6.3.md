# LeoDeepAI 0.6.3(Windows x64)

## 变更

- 云服务地址默认值统一为 `https://api.leodeepai.com`:桌面端页面构建与本地 BFF 转发两处一致,旧域名不再作为默认值。
- 包含 0.6.x 系列的全部改动:会话头部动作区重做(子智能体 / 智能体团队 / 后台任务收进同一动作条)、子智能体会话与父会话共用输入卡、Web 手机宽度适配、本机文件夹在资源管理器打开等。
- 本次提供 Windows x64 安装包;macOS / Linux 仍为 0.6.0。

## 安装

下载下方 `LeoDeepAI_0.6.3_x64-setup.exe` 直接安装,可从 0.6.2 覆盖升级。

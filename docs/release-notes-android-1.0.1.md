# LeoDeepAI Android 1.0.1

发布日期：2026-11-17

- **项目与会话按项目边界分组**：进入项目只看本项目会话，「不在项目中工作」不再混入其它项目；正在运行的会话在顶部单独一组。
- **项目编辑器支持文件夹选择器**：可直接浏览电脑端本机或已连接服务器上的目录，不再只能手输绝对路径；服务器选择器显示别名。
- **反馈页改版**：描述与截图合并为一块，字数计数更准确（emoji 按一个字算），直接显示当前版本号。
- **输入区、列表与工作区交互优化**：视觉细节与桌面端对齐，修复若干问题。

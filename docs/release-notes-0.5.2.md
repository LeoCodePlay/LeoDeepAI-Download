## 本次包含

- 输入区改为富文本编辑：正文里的 `/技能名`、`@文件` 会渲染成带图标的引用 chip（悬停可删除）；输入法组词期间不重建 DOM，复制/剪切仍输出原始引用词。
- 项目管理改为「一个项目 = 名字 + 一组并列文件夹」：文件夹可以来自多台服务器，也可以来自本机；项目选择面板与左侧栏共用同一份项目悬停卡（文件夹路径、服务器别名、离线/已删除状态）。
- 设置里新增「管理能力」页：插件、技能、MCP 三个页签常驻挂载，统一搜索、上传与启停，切换页签不丢滚动位置与展开状态。
- 本机访问判定：只有用户在本轮提问里明确要求（给出本机路径、要求搜索/查看本机、或用 @ 引用本机文件）时才放行本机工具，其余情况仍默认拒绝，避免 AI 擅自越出项目范围。
- Agent 侧同步调整：项目文件夹作用域与工具寻址、传输队列、浏览器工具后端、会话与设置存储。
- 文件管理器、目录浏览、终端面板、工作区面板，以及浏览器扩展 `page-ops.js` 的界面与交互细节更新。
